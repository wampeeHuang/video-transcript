# 清洗规则

> 三个分支共用。提取后的原始文本 → 干净文案，靠这套规则。清洗是 LLM 语义判断，不是脚本。

## 通用规则

1. **修错字**：基于上下文修正识别错误。语音识别（ASR）出**音近错**，OCR 出**形近错**，两类都要修。
2. **繁转简**：繁体字转简体。
3. **去噪声**：删片头片尾台标（"感谢观看""字幕组"）、水印、ASR 幻觉重复（"土豆土豆土豆"）、乱码词。
4. **按语义分段**：一个完整意思一行，一句到 `。？！` 或自然停顿为止。
5. **不添油加醋**：不补写原文没有的内容，不总结，只清理。
6. **句内中文标点**：逗号、顿号用中文；句末用 `。？！`。**不保留半角逗号 `,`**。
7. **拿不准不瞎改**：音译专有名词拿不准的保留原样，列出交用户定。宁保留不二次污染。

## 正字表

音近错 → 正确写法的映射，数据在 `references/corrections.md`。清洗时按表改，拿不准的保留不瞎改。

## 三个分支各自的噪声重点

| 分支 | 主要噪声 | 清理重点 |
|---|---|---|
| 软字幕 | ASR 音近错字、繁简混排 | 正字表 + 繁转简 |
| 硬字幕 OCR | 场景字（品牌名、警示语、水印、摄影署名）、动画拆开的短字幕、形近错字 | 去场景字 + 合并短字幕 + 纠形近错 |
| 音频 ASR | 幻觉重复、台标、无意义片段 | 去幻觉 + 去台标 + 删乱码 |

具体见各分支文档。
